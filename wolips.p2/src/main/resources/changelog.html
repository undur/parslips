Changelog

What's new in Parsley Template Editor

February 27, 2026

New Project wizard

Create new ng-objects or WebObjects projects from scratch — complete Maven projects with a sample Main component, ready to run. The wizard generates all source files and imports the project via m2e.

Smarter New Component wizard

The New Component wizard now defaults to the project's components folder and handles a wider variety of Package Explorer selections gracefully.

Removed woenvironment.jar dependency

The vendored woenvironment.jar (which wasn't tracked by git) has been eliminated. All functionality it provided has been replaced with lightweight inline implementations. This fixes CI builds and removes a hidden dependency.

February 26, 2026

Full editor support for standalone HTML templates

Single-file .html templates (not inside .wo bundles) now have full editor support: autocomplete, keypath validation, and build-time validation — all on par with traditional .wo components. This is a key enabler for ng-objects, where single-file templates are the primary component format.

WOD validation thread-safety fix

Fixed a long-standing intermittent bug inherited from WOLips where validation would report false errors — e.g. "exactly one of 'count' or 'list' must be bound" on a WORepetition that was correctly bound. The root cause was concurrent DOM access to the shared API model.

Dual framework support

The plugin now works with both ng-objects and WebObjects projects in the same workspace. Per-project framework detection uses build.properties (base=ng or base=wo) with automatic classpath probing as a fallback.

Element type autocomplete filtering

Tag autocomplete now correctly filters to only show element types (subclasses of NGElement or WOElement), instead of listing every Java class in the project.

February 25, 2026

Initial release

Parsley Template Editor — extracted from the WOLips plugin suite (~18 plugins merged into one bundle), rebuilt as a standalone Eclipse plugin with unique identifiers for coexistence with WOLips.

Multi-tab component editor

Edit HTML template, WOD bindings, and WOO settings in a single tabbed editor — for both .wo bundles and standalone .html templates.

Tag and binding autocomplete

Autocomplete for wo: tags and binding attribute names, with keypath validation against the component's Java class.

Syntax highlighting

Distinct colors for OGNL keypaths, constant strings, and dynamic binding tags. A subtle background tint on <wo:> tags makes component boundaries easy to spot.

Parsley Explorer

A Package Explorer variant with component-aware behavior: .wo bundles are expandable (unlike WOLips), source folders like src/main/components are pulled up to the project root, and everything gets the right icons and decorators.

Parsley perspective

A dedicated perspective with the Parsley Explorer, editor area, Problems/Console views, and Outline — ready for component development out of the box.

Insert component toolbar

Quick-insert buttons for common WebObjects elements: WOForm, WORepetition, WOConditional, WOString, WOHyperlink, and more.

Editor association

Component files (.html, .wod, .woo, .api) automatically open in the Parsley editor — for any file inside a .wo folder, or for component files in ng-objects projects.
