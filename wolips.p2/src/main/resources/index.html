Parsley Template Editor

A template editor for WebObjects and ng-objects components

⚠️ Early Development

Parsley is under active development, so you might want to try it in a fresh Eclipse installation to be safe (although testing it alongside WOLips is great for us too). Please report any problems you encounter — since we’re in early development, reported bugs are usually fixed fast.

Installation

  1. In Eclipse, go to Help → Install New Software...
  2. Click Add to add a new update site
  3. Enter the update site URL: https://undur.github.io/parslips/repository/
  4. Select Parsley Template Editor from the list and follow the prompts to install

What you get

  1. A multi-tab component editor for .wo bundles and standalone templates
  2. Tag and binding autocomplete, keypath validation, syntax highlighting
  3. An LSP server for wo: tag intelligence in any editor
  4. Works with both ng-objects and WebObjects projects
